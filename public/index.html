How to deploy on Vercel
1. Push this project to a GitHub repo (github.com → New repository → upload files)
2. Go to vercel.com → New Project → Import your GitHub repo
3. In Vercel project settings → Environment Variables → add your keys
4. Click Deploy — Vercel builds and gives you a live URL in ~60 seconds
Environment variables to add in Vercel
ANTHROPIC_API_KEY — from console.anthropic.com (required)
YOUR_NAME — your name for email sign-offs
YOUR_ROLE — your job title / role
MS_CLIENT_ID / MS_CLIENT_SECRET / MS_TENANT_ID / MS_USER_EMAIL — add when ready
FATHOM_API_KEY — add when ready
